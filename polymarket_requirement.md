⚠️ 安全前提(請先看)

  - 不要把私鑰貼進這個對話。放進專案本機的 .env(我會用 python-dotenv 讀),這個 repo 目前不是 git repo,但仍請別讓 .env 進任何會分享的地方。
  - 用一個全新的「拋棄式」錢包,不要用你的主錢包。只放小額資金(夠跑極小單即可,例如 20–50 USDC + 幾塊 MATIC 當 gas)。
  - M0/M2.5 會送極小真單並做鏈上 split/merge——這就是為什麼要 dedicated wallet + 小額。
